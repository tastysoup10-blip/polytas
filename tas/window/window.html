Writing inputs

    
Each line says which keys are held from that millisecond on, until the next line:

    
0,w          hold W from the start
1000,wd      from 1.000 s: W and D
1450,w       from 1.450 s: only W (D let go)
2000,none    nothing held

    
Keys are w a s d and r (reset), in any order. A line lists everything held: a key that is not written is not held. Lines can be in any order; at the same time, the later line wins.

    
# starts a comment. A tap line alternates keys with whatever was held before it:

    
tap 3000 3400 a 20 30   from 3.000 to 3.400 s: A for 20 ms,
                        then back for 30 ms, and again…

    
Nothing changes in the game until you Apply; then that car runs again from the first millisecond you changed — the same run the game itself would play.
